# ytModify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one Manifest V3 Chrome extension, ytModify, that combines reliable auto pop-out (PiP), four switchable look styles, and a full rebuild of Ambient light for YouTube, all controlled from one toolbar popup.

**Architecture:** One Rollup + Sass build turns `src/` into `dist/`. ytModify's own settings live in `chrome.storage.local` under `ytm-*` keys. Ambient keeps its `setting-<name>` keys. The popup writes those keys, and content scripts apply the changes live:
- **Look** is a set of `<style>` elements in each YouTube frame.
- **PiP** is a single controller in the page's own (MAIN) world, fed by a relay in the extension's isolated world and a background focus signal.
- **Ambient** is the ported source, with its in-player menu replaced by a storage bridge that reuses the menu's original change logic.

**Tech Stack:** JavaScript (ES modules), Chrome MV3, Rollup 4 + Babel (as in Ambient), Sass, `node:test` for unit tests (no test framework dependency), Node 24 (installed: v24.22.1).

## Review Focus

1. **YouTube's single-page navigation** (watch → home → another watch without a reload): styles, PiP and Ambient must all re-attach to the new `<video>`. Covered by the Task 4 and Task 11 manual checks.
2. **Several YouTube tabs open while popup changes are made:** every tab updates. Bar sizes auto-detected in one tab must not leak into the others. Covered by the Task 6 `extractPopupChanges` tests and the Task 11 check.
3. **Extension reloaded while YouTube tabs stay open** ("orphaned" content scripts): no uncaught errors flood the console. Every `chrome.*` call in content scripts must be guarded by `chrome.runtime?.id`. Covered by the Task 2 `safeStorage` test and the Task 11 check.
4. **Non-watch pages and embeds** (home, search, channel, `/embed/`, `/live_chat`): Look applies everywhere except `/premium` and `/howyoutubeworks`, and PiP and Ambient do nothing harmful. Covered by the Task 3 `isLookExcludedPath` test and the Task 11 check.
5. **Paused, ended or ad-playing video at tab switch:** no pop-out for paused or ended videos, and no error spam. Covered by the Task 4 `decidePip` tests.
